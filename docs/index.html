FirnPlanner

今日の​予定を、​ 一枚の​テキストに。Your day, on a single page of text.

FirnPlanner は​ 1日1ファイルの​ Markdown で​予定と​実績を​書く​ macOS の​デイリープランナーです。​チェックボックスの​行を​書くと、​その​瞬間に​タイムラインへ​置かれます。FirnPlanner is a daily planner for macOS that keeps each day in one Markdown file. Type a checkbox line and it lands on the timeline the moment you write it.
