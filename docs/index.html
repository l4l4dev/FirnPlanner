FirnPlanner

1日1ファイルの Markdown で予定と実績を書く、macOS のデイリープランナーです。

チェックボックスの行を書くと、その瞬間にタイムラインへ自動で配置されます。時刻や所要時間を別画面で入力する必要はありません。ファイルの実体は Markdown 1日1ファイルなので、他のエディタやツールでも読み書きできます。

β版について (重要)

現在配布しているビルドは Apple の公証 (notarization) を受けていません。そのため、初回起動時に macOS の Gatekeeper が「"FirnPlanner" は開発元を確認できないため開けません」のような警告を出してアプリを開けないことがあります。これは既知の状態で、以下の手順で開けます。

  1. 一度、警告のダイアログを閉じる
  2. 「システム設定」→「プライバシーとセキュリティ」を開く
  3. 下の方にある「このまま開く」ボタンをクリックする

または、Finder でアプリを右クリック (もしくは Control キーを押しながらクリック) →「開く」を選ぶ方法でも開けます。
