FirnPlanner プライバシーポリシー

最終更新: 2026-08-26

FirnPlanner は macOS 上で動くデイリープランナーです。あなたが書いた予定・タスク・振り返りは、あなたが選んだフォルダの Markdown ファイルとして、あなたの Mac にだけ保存されます。開発者のサーバーはありません。

通信が発生する場合

通信が発生するのは次の2つだけです。

  1. Google カレンダー連携をオンにしてログインした場合: Google カレンダーの予定を読み取り専用 (スコープ calendar.readonly) で取得し、タイムラインに表示します。取得した予定は表示とオフライン時のキャッシュのためにあなたの Mac 内に保存され、外部には送りません。ログイン情報 (トークン) は Google Sign-In SDK が macOS のキーチェーンに保存します。設定からログアウトすると消えます。
  2. Markdown に画像の URL を貼り付けた場合: その画像を1回ダウンロードして、あなたの Mac 内に取り込みます。

Google のユーザーデータの取り扱い

Google のユーザーデータの利用は、Google API サービスのユーザーデータに関するポリシー (制限付き使用の要件を含む) に従います。カレンダーのデータを第三者に提供したり、広告に使ったり、アプリの機能以外に使うことはありません。

解析・トラッキング

現在は使用していません。将来、配布ページ (このサイト) にアクセス解析を入れる場合は、このページで告知します。

データの削除

ファイルはあなたのフォルダにあるので、削除はあなたが行えます。Google との接続解除は、アプリの設定からのログアウト、または Google アカウントの「サードパーティのアクセス」から取り消せます。
